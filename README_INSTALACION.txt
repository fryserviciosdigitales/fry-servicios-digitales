PUBLICACIÓN GRATUITA
OPCIÓN A - GitHub Pages
1. Crea una cuenta en github.com.
2. Crea un repositorio público llamado fry-servicios-digitales.
3. Sube todos los archivos manteniendo la carpeta assets.
4. En Settings > Pages, selecciona Deploy from a branch y main / root.
5. GitHub generará la dirección pública.

OPCIÓN B - Cloudflare Pages
1. Crea una cuenta gratuita.
2. Crea un proyecto Pages y conecta el repositorio.
3. No necesitas comando de compilación.
4. La carpeta de salida es la raíz del proyecto.

PERSONALIZAR LOGO
Sustituye assets/logo-fry.png por tu logo real conservando el mismo nombre, o cambia las referencias en index.html y manifest.json. Se recomienda PNG o SVG cuadrado, con buena legibilidad a tamaño pequeño.
